Reports ${property} placeholders in Java templates (templating-maven-plugin) that cannot be resolved.

A property is resolved when it is declared in the <properties> of the module pom or of its parents, when it is a project model property such as project.version, or when the Maven model already provides it. System and environment properties (env.*, java.*, os.*, user.*, settings.*, maven.*) are never reported.

The quick fix adds an empty property to the pom of the module.
